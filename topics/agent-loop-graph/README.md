- [C-05 两把尺子：单页预算与总账预算](cards/C-05-两把尺子-单页预算与总账预算.md)：context.max-tokens 管单次 prompt 多长，looptrip.max-tokens 管整次规划花多少钱。
- [C-06 四层记忆：按生命周期分层](cards/C-06-四层记忆-按生命周期分层.md)：工作记忆、会话记忆、用户记忆、系统知识，四种寿命，四个隔层。
- [C-07 偏好晋升三条判据](cards/C-07-偏好晋升三条判据.md)：频次至少 3 个会话、方向一致、有条件就连条件一起确认。
- [C-08 召回与遗忘：记忆越准越好](cards/C-08-召回与遗忘-记忆越准越好.md)：相关性挑前 8 条；90 天未用降置信度 0.25，低于 0.3 自动删除。
- [C-09 显式约束压过历史画像](cards/C-09-显式约束压过历史画像.md)：用户这次说的精确数字，永远比历史推断优先；不需要额外的冲突仲裁器。
- [C-10 记忆三件套：可解释、可查看、可删除](cards/C-10-记忆三件套-可解释-可查看-可删除.md)：说不清为什么记、看不到记了什么、删不掉记错的内容，这样的记忆系统不该上线。

### L Loop 与验收

- [L-01 Function Calling 的本质：模型只开口，程序才动手](cards/L-01-Function-Calling-的本质-模型只开口-程序才动手.md)：模型说出想调什么，Java 进程真正执行；权限、失败、账单都留在宿主一侧。
- [L-02 查不到就说「没有」：事实纪律](cards/L-02-查不到就说-没有-事实纪律.md)：空列表原样返回，配合工具描述和系统提示词形成纪律；宁可说不知道，不说好听的假话。
- [L-03 两层循环：内层管信息，外层管合格](cards/L-03-两层循环-内层管信息-外层管合格.md)：框架的工具循环解决「信息够不够」，我们写的业务循环解决「结果行不行」。
- [L-04 停止权为什么必须在宿主手里](cards/L-04-停止权为什么必须在宿主手里.md)：模型没有资源观、不掌握业务标准、还存在取悦倾向，三个理由决定它不能决定停不停。
- [L-05 Loop 四步与状态六字段](cards/L-05-Loop-四步与状态六字段.md)：决策、执行、观察、判断；前两步决定能不能干活，后两步决定能不能被信任。
- [L-06 循环与重试的分界线：问题有没有进入下一轮](cards/L-06-循环与重试的分界线-问题有没有进入下一轮.md)：重试是同一张卷子重考，循环是老师圈出错题再答一遍。
- [L-07 把形容词翻译成谓词：四步提取法](cards/L-07-把形容词翻译成谓词-四步提取法.md)：列抱怨、翻现象、找数据源、分级别，任何业务都能提取出可计算标准。
- [L-08 HARD 与 SOFT 分通道](cards/L-08-HARD-与-SOFT-分通道.md)：硬约束决定能不能交付，软偏好决定好不好；软的不阻塞，硬的进返工单。
- [L-09 验证金字塔与数据天花板](cards/L-09-验证金字塔与数据天花板.md)：确定性验证放底层，启发式放中层，判读性放顶层；能算准的不要交给模型凭感觉。
- [L-10 七条交付标准 C1-C7](cards/L-10-七条交付标准-C1-C7.md)：五个 HARD 全过才算完成，两个 SOFT 进报告不阻塞。
- [L-11 结构化输出与取消记账权](cards/L-11-结构化输出与取消记账权.md)：让模型按表格交付，同时删掉它的 total 字段：程序能算准的，不让模型算。
- [L-12 只信名字，不信价格](cards/L-12-只信名字-不信价格.md)：拿行程里的酒店名、航班号、景点名回查快照单价再求和，查不到就判失败。
- [L-13 约束四件套与统一返回结构](cards/L-13-约束四件套与统一返回结构.md)：确定性、可定位、可建议、互相独立；每条约束返回编号、级别、证据、建议。
- [L-14 生成与验证分离：假合格的三种成因](cards/L-14-生成与验证分离-假合格的三种成因.md)：让写作文的人给自己打分，分数不可信；验收权必须固定在模型外面。
- [L-15 一个出口：problems.isEmpty()](cards/L-15-一个出口-problems.isEmpty.md)：生成侧、契约层、交付层三个入口汇总成一份清单，清单为空才算本轮通过。
- [L-16 返工单质量决定收敛速度](cards/L-16-返工单质量决定收敛速度.md)：反馈越具体，下一轮搜索空间越小；返工单在写检查那一刻就决定了。
- [L-17 进度尺：停滞、震荡与 bestRound](cards/L-17-进度尺-停滞-震荡与-bestRound.md)：用问题数量严格变少定义「更好」，到上限时返回问题最少的一轮。

### H Harness 与停止

- [H-01 八种失控模式](cards/H-01-八种失控模式.md)：原地类四种：空转、震荡、发散、资源爆炸；进攻类四种：幻觉推进、补偿过度、卡死、权限逃逸。
- [H-02 三层根因：模型、系统、交互](cards/H-02-三层根因-模型-系统-交互.md)：模型没有资源观和元认知，系统缺少外部观测与预算，交互目标模糊且环境不确定。
- [H-03 Harness：终止权必须外置于执行者](cards/H-03-Harness-终止权必须外置于执行者.md)：挽具不削弱马力，只让力量可用；三个跨领域案例指向同一个结论。
- [H-04 Harness 四条设计原则](cards/H-04-Harness-四条设计原则.md)：控制权分离、预算先行、可观测优先、优雅降级。
- [H-05 四道护栏 G1-G4 与优先级](cards/H-05-四道护栏-G1-G4-与优先级.md)：无进展、Token 预算、总超时、轮次上限；按信息量从高到低排序，第一条触发即停。
- [H-06 前置预估：Admission Control](cards/H-06-前置预估-Admission-Control.md)：已用加预估下一轮超过上限，就不启动这一轮；事后拦截差的正好是最贵的那一轮。
- [H-07 while(true) 与带身份证的 return](cards/H-07-while-true-与带身份证的-return.md)：反面写法是 while(round < max && ...)，退出后不知道为什么停；正解是每个出口带自己的终态。
- [H-08 账本与只读快照](cards/H-08-账本与只读快照.md)：引擎记账，护栏拿复印件：可以看，不能改。
- [H-09 终态是用户行动指南](cards/H-09-终态是用户行动指南.md)：SUCCESS 看结果，GUARDED 放宽条件，INFEASIBLE 改需求，UNSUPPORTED 换工具，CANCELLED 重新决定。
- [H-10 诚实失败的三条红线](cards/H-10-诚实失败的三条红线.md)：HARD 失败不能降级成 warning；警告必须具体到位置；状态标签与文案必须一致。
- [H-11 技术重试与业务返工分开记账](cards/H-11-技术重试与业务返工分开记账.md)：重试解决「没听清」，循环解决「做错了」；两条路的预算分开。
- [H-12 退出地图：先穷举怎么停，再写怎么跑](cards/H-12-退出地图-先穷举怎么停-再写怎么跑.md)：六行表格先于代码存在，每行对应一种终态和一种用户动作。
- [H-13 固定回放与 calls 断言](cards/H-13-固定回放与-calls-断言.md)：回放要证明的是「无论模型犯什么错，宿主都能在边界前停住」。「模型什么时候犯错」本来就不可控。

### I 交互与人在环

- [I-01 黑盒的三笔账：看不见、按不动、接不上](cards/I-01-黑盒的三笔账-看不见-按不动-接不上.md)：同一份执行信息迟到了 27 秒；用户既不能叫停，也不能带着上一版修改。
- [I-02 什么时候必须白盒化](cards/I-02-什么时候必须白盒化.md)：执行时间长、结果高度个人化、每一轮都在花钱，三条全中就必须做。
- [I-03 事件设计：从用户的决策反推](cards/I-03-事件设计-从用户的决策反推.md)：不推「系统能说什么」，推「用户此刻要做什么决定」。
- [I-04 SSE 选型：判据先行，技术后行](cards/I-04-SSE-选型-判据先行-技术后行.md)：单向、纯文本、穿普通网关、断线自动重连，四条全中。
- [I-05 脱敏白名单：新字段默认不安全](cards/I-05-脱敏白名单-新字段默认不安全.md)：只有名单上的 key 才放行；白名单跟判据长，犯错方向永远是「少推了」。
- [I-06 可观察性不得控制主流程](cards/I-06-可观察性不得控制主流程.md)：emit 里 catch 掉所有异常，注释只有一句：观测不能控制规划流程。
- [I-07 双层 Loop：内层求合格，外层求合意](cards/I-07-双层-Loop-内层求合格-外层求合意.md)：引擎自动跑到合格，人只判断机器判断不了的那部分。
- [I-08 会话状态机：终态复用，过程态新增](cards/I-08-会话状态机-终态复用-过程态新增.md)：CREATED、RUNNING、REVISING、CLOSED 是新增过程态，五个终态原样复用。
- [I-09 取消的三条语义](cards/I-09-取消的三条语义.md)：不掐断当前调用，返回最好一版，延迟要诚实说。
- [I-10 续修还是新会话：上一版还有参考价值吗](cards/I-10-续修还是新会话-上一版还有参考价值吗.md)：改完之后上一版还能参考就续修，不能参考就开新会话。
- [I-11 回滚就是切指针](cards/I-11-回滚就是切指针.md)：每版追加一条记录，回滚把指针指回去，0 次模型调用。
- [I-12 意图识别六法：按成本级联](cards/I-12-意图识别六法-按成本级联.md)：规则、NLU、LLM 结构化输出、Tool calling、向量检索、级联混合；生产系统基本都是级联。
- [I-13 闭集动作与两个兜底出口](cards/I-13-闭集动作与两个兜底出口.md)：六个进 Loop 的动作，三个不进的出口；输出空间不能大于执行空间。
- [I-14 识别器可以幻想，策略器不许](cards/I-14-识别器可以幻想-策略器不许.md)：模型可以提议数字，不能替用户拍板；越界点必须在代码里看得见。
- [I-15 三档验证与七个维度](cards/I-15-三档验证与七个维度.md)：能 assert 写测试，能算分做评测，剩下才交给人；顺序不能反，不许降级使用。
- [I-16 误判按代价加权，不按数量平均](cards/I-16-误判按代价加权-不按数量平均.md)：总准确率 76% 不可怕，危险误判 0 次才是关键。

### G Graph 与并行

- [G-01 Loop 是 Graph 的特例](cards/G-01-Loop-是-Graph-的特例.md)：while 的一条回边，就是图上的一条边；图不替代 Loop，它把控制流展开。
- [G-02 五个升级信号](cards/G-02-五个升级信号.md)：可并行、分支多、返工范围不同、需要等人、团队要看结构。
- [G-03 图化的收益与必须承担的代价](cards/G-03-图化的收益与必须承担的代价.md)：依赖写成边、回边落在哪、等待成为节点、一份声明三处复用。
- [G-04 三步长大：3 节点 7 边、7 节点 14 边、8 节点 16 边](cards/G-04-三步长大-3-节点-7-边-7-节点-14-边-8-节点-16-边.md)：先等价迁移，再打开并行，最后加入暂停恢复；一次只增加一种不确定性。
- [G-05 等价迁移怎么证明没改坏](cards/G-05-等价迁移怎么证明没改坏.md)：输入相同、关键轨迹相同、结果相同，旧测试不改也能过。
- [G-06 四件套与「先合并再选边」](cards/G-06-四件套与-先合并再选边.md)：节点是工位，边是路牌，状态是工单，终态是结果章；选边必须在合并之后。
- [G-07 并行前沿与 JoinSpec：只等最慢一项](cards/G-07-并行前沿与-JoinSpec-只等最慢一项.md)：四路只读同一份请求，谁也不等谁，收齐数据或降级说明后 generate 只启动一次。
- [G-08 故障隔离与质量裁决分开](cards/G-08-故障隔离与质量裁决分开.md)：JoinSpec 只管人是否都回来了，validate 才管手里的东西够不够交付。
- [G-09 到点收口，迟到不采用](cards/G-09-到点收口-迟到不采用.md)：单节点 5 秒、整组 10 秒；只有完成时间不晚于截止时间的结果才能合入状态。
