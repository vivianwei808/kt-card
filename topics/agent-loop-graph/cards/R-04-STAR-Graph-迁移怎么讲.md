# R-04 STAR：Graph 迁移怎么讲

> S 依赖难解释，T 不破坏旧行为，A 五步迁移，R 可定位但记录不天然提速。

## 机制

- S 情境：四类查询都在 while 里，依赖关系与失败影响难以解释。
- T 任务：不破坏旧行为，让复杂依赖显式化。
- A 行动：补基线、串行等价迁移、确认一致、拆并行与等待节点、补验证。
- R 结果：依赖与失败范围可定位；同时记录 Graph 本身不天然提速。
- 重点放在 Action，结果要带限定条件。
- 追问预埋：为什么先等价迁移、怎么证明没改坏、迟到结果怎么处理。

## 代码落点

- `Chapter9GraphMigrationReplayTest`：等价性证据
- `TravelGraphFactory`：迁移结果
- `LightGraph`：执行器

## 复用清单

- STAR 的 R 一定要带边界，否则会被追问到无法收场。
- 准备两层追问：每层一个事实加一个判断。

## 面试一句话

我先用测试钉死旧行为，再做等价迁移，最后拆并行和等待；性能收益只在事实层可测，整体仍看生成占比。

## 常见坑

把 R 讲成「性能提升 3 倍」。没有同条件计时，这个数字站不住。
