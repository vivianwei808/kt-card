# R-08 后端背景的转型叙事与减分答法

> 保留契约、状态、一致性、故障恢复的优势，补 Context、模型失败、验收评测。

## 机制

- 可迁移优势：API 契约、数据库事务与幂等、并发缓存鉴权、监控部署与故障恢复。
- 新增缺口：模型 API 与失败模式、结构化输出、Context 组织、Tool Calling、独立验收器与评测。
- 最小证明：在原业务里增加受控 Agent 入口，白名单查询工具、结构化处置建议、权限与必填验收、不合格返工、高风险转人工。
- 叙事主线：把不稳定模型放进稳定系统。亮点不在「也会写 Prompt」。
- 自我介绍结构：背景、可迁移优势、项目补强、目标岗位。
- 减分答法：从技术栈背起；答「我加了重试和超时」；把 Graph 等于更快；把模型自评当验收。
