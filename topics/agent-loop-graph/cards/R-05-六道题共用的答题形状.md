# R-05 六道题共用的答题形状

> 先给框架，再填证据，最后自己划边界。

## 机制

- 画地图题（一分钟总览）：每段只埋一个入口。
- 概念题（Agent 与 LLM 的区别）：先定义，再逐项映射到自己的代码。
- 机制题（Loop 怎么设计）：讲状态、转移、出口、进展判据。
- 选型题（为什么上 Graph）：先讲什么时候不需要，再讲如何保持行为一致。
- 护栏题：破题一句「保护对象不同」，再讲四类失控对应四道护栏。
- 收尾反问：团队最核心的 Agent 场景、验收更看重效果还是稳定性、能否参与真实数据与发布。
- 六道题共用同一个动作：框架、证据、边界。

## 代码落点

- `第10章 28/35 到 35/35`
- `机制题的四个答案`：状态五样、一轮三步、转移四种、指纹判据

## 复用清单

- 每道题先想形状，再想内容。形状对了，内容不会散。
- 每个回答留一个可追问点，把面试引到你准备最充分的地方。

## 面试一句话

（按题型的形状作答，每段末尾主动停一下，等对方追问。）

## 常见坑

问什么答什么，答完就停。没有框架也没有边界，听起来像背书。
