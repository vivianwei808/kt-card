# R-06 三个高频追问的标准答法

> 为什么不用更强模型、为什么加护栏、Graph 是否更快，三题都有固定反打。

## 机制

- 为什么不用更强模型：价格编造、格式漂移、不会自改，三个问题换模型都解决不了，它们属于宿主责任。
- 已经有结果检查，为什么还要护栏：保护对象不同。业务检查保护结果质量，护栏保护执行过程。
- 护栏和重试超时有什么区别：重试是容错，护栏是止损。
- Graph 是不是更快：主收益是可维护性与可测试性，性能只是事实层的副产品。
- 为什么取消不能立刻生效：这一轮的钱已经花了，取消作用于下一次调用。
- 每个回答都先破题一句，再展开三点以内。

## 复用清单

- 把这三题写成 30 秒版本，背熟。
- 答案里带一个具体数字，可信度会明显不同。

## 面试一句话

换模型治不了宿主的问题；护栏保护过程，检查保护结果；Graph 买的是可维护性。

## 常见坑

回答「因为更规范」「因为更先进」。这类词在追问下没有落脚点。
