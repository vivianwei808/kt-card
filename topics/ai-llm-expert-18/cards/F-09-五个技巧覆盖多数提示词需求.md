# F-09 五个技巧覆盖多数提示词需求

> 要程序解析就让它输出 JSON，要准确就给样例，要多步推理就写 CoT。

## 机制

- 限制输出格式：要求 JSON 返回并给字段结构，方便代码直接解析。
- 用三引号等分隔符把多段输入隔开，模型不容易混淆不同文本。
- 提供样例处理有歧义的任务，样例里连判断理由一起给。
- CoT 把任务拆成步骤并给出计算过程示例，提升透明度和准确率。
- 面向不同角色讲解，例如「把我当五岁小朋友解释超导体」，控制输出深度。

## 代码落点

- `JSON mode`：固定字段输出
- `few-shot`：给输入输出样例
- `CoT`：要求写出推理步骤
- `分隔符`：三引号或 XML 标签

## 复用清单

- 凡是下游要解析的输出，先定 JSON 字段再写提示词。
- 分类任务先给 3 到 5 个带理由的样例。

## 面试一句话

提示词技巧按目标选：格式约束给程序用，样例给歧义任务用，CoT 给推理任务用。

## 常见坑

只说要 JSON 却不给字段结构，模型每次返回的键都不一样。
