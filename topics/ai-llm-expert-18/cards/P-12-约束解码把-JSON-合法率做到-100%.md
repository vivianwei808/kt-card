# P-12 约束解码把 JSON 合法率做到 100%

> 正则转压缩 FSM，无效 token 概率置零，Prompt 工程只有 90% 到 95%。

## 机制

- 请求里传 regex，把正则表达式编译成有限状态机，解码时逐 token 过滤。
- 压缩 FSM 把相邻的单次转换边合并，一条边可一次解码多个 token。
- 常量片段在普通 FSM 里要多次前向，压缩后一步完成。
- 格式正确率 100%，不再需要 try-except 加重试。
- 正则只约束形状，字段内容仍由模型生成。

## 代码落点

- `regex`：输出约束
- `sampling_params`：解码参数
- `Compressed FSM`：压缩状态机
- `/generate`：SGLang 接口

## 复用清单

- 下游要解析 JSON，就用约束解码替代提示词叮嘱。
- 常量前缀多的格式收益最大。

## 面试一句话

约束解码在采样层排除非法 token，格式问题从工程问题变成数学保证。

## 常见坑

用 Prompt 反复强调输出 JSON，仍要写重试和兜底解析。
